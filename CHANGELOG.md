# Changelog

All notable changes to IMacAsMonitor are documented here.

## 0.5.0 — 2026-10-19

- Renamed the project, executable, app bundle, Bonjour service, and virtual
  display from MacAsMonitor to IMacAsMonitor.
- Added automatic Bonjour receiver discovery with Thunderbolt Bridge preference.
- Added receiver-driven logical size, Retina backing resolution, and refresh
  rate negotiation.
- Added an experimental virtual HiDPI extended display mode.
- Added full-screen menu bar and Dock auto-hide behavior.
- Added Command-Q, a Quit button, and clean window-close termination.
- Added the standalone installation and troubleshooting guide.
- Added public repository metadata, CI, licensing, and contributor documentation.

## 0.1.0–0.4.0

- Built the initial ScreenCaptureKit, VideoToolbox, TCP, and Metal mirroring
  pipeline for an M1 Max source and 2017 MacBook Pro receiver.
