IMacAsMonitor 0.5.0

Installation and setup guide

Use a 2017 MacBook Pro—or later your 2017 iMac—as an extended display for the M1 Max MacBook Pro over Thunderbolt Bridge.

Contents Requirements Install Thunderbolt Bridge Connect automatically Find the receiver IP Use and quit Troubleshooting

1. What you need

Source Mac

16-inch M1 Max MacBook Pro. It creates and captures the virtual extended display.

Receiver Mac

2017 MacBook Pro. It decodes the video and displays it full-screen.

  • A Thunderbolt cable connecting the two Macs
  • IMacAsMonitor-0.5.0.zip
  • Administrator access for macOS privacy and firewall settings
  • Both Macs connected to power for the first test
The virtual display uses an undocumented macOS interface. This is appropriate for a personal, locally installed tool, but a future macOS update could require changes.

2. Install the app on both Macs

  1. Quit any older version of IMacAsMonitor on both Macs. Press Command-Q, or run killall IMacAsMonitor in Terminal for an older version that will not quit.
  2. Double-click IMacAsMonitor-0.5.0.zip to extract it.
  3. Drag IMacAsMonitor.app into the Applications folder.
  4. Copy the same ZIP file to the 2017 Mac and repeat these steps there.
  5. For the first launch, Control-click the app, choose Open, and confirm Open if macOS warns that it was not downloaded from the App Store.

Permissions on the source M1 Mac

  • Allow Local Network access if requested.
  • Allow Screen Recording in System Settings → Privacy & Security → Screen Recording.
  • If you just enabled Screen Recording, quit and reopen IMacAsMonitor.

Permissions on the receiver Mac

  • Allow Local Network access if requested.
  • If the firewall asks, choose Allow incoming connections.

3. Check Thunderbolt Bridge

  1. Connect the Macs directly with the Thunderbolt cable.
  2. On each Mac, open System Settings → Network.
  3. Select Thunderbolt Bridge.
  4. Confirm that its status is connected or active.
An address beginning with 169.254. is normal. It is a self-assigned link-local address used for the direct connection and does not mean the connection failed.

4. Connect automatically

  1. On the 2017 MacBook Pro, open IMacAsMonitor and click Start Receiver.
  2. Wait until its status says that the receiver is advertised automatically.
  3. On the M1 Max, open IMacAsMonitor.
  4. Leave Receiver address (optional) empty.
  5. Leave Create a virtual extended display selected.
  6. Click Start Source.

The source uses Bonjour to discover the receiver. It prefers the Thunderbolt Bridge interface named bridge0. A successful status resembles:

Found Haious-MacBook-Pro via bridge0. Connecting…

The receiver then reports its logical resolution, backing-pixel resolution, and refresh rate. The source uses that information to create and stream the virtual display.

5. Find the receiver’s IP address manually

You normally do not need an IP address with version 0.5.0. Use these instructions only if automatic discovery does not find the receiver.

Method A — System Settings

  1. On the receiver, open System Settings → Network.
  2. Select Thunderbolt Bridge.
  3. Click Details, then select TCP/IP.
  4. Copy the IPv4 Address. It should look similar to 169.254.143.183.
  5. Enter that address in the source Mac’s optional receiver-address field, then click Start Source.

Method B — Terminal

Open Terminal on the receiver and run:

ipconfig getifaddr bridge0

If that produces no output, inspect the interface directly:

ifconfig bridge0 | grep "inet "

Example output:

inet 169.254.143.183 netmask 0xffff0000 broadcast 169.254.255.255

The receiver address in this example is 169.254.143.183.

Verify the connection from the source

Replace the example address if yours is different:

ping -c 4 169.254.143.183

Replies confirm basic IP connectivity. A new link-local address may be assigned after disconnecting or restarting the Macs, which is why automatic discovery is preferred.

6. Arrange and use the extended display

  1. On the M1 Max, open System Settings → Displays → Arrange.
  2. Place IMacAsMonitor Extended Display to the left or right of the M1 display.
  3. Move the source pointer or drag a window across that edge.
  4. The 2017 Mac displays the virtual desktop full-screen. Its menu bar and Dock hide automatically.
Use the M1 Mac’s keyboard and trackpad to control the extended desktop. Input forwarding from the receiver is not implemented yet.

Stop or quit

  • Press Escape on the receiver to leave presentation mode and restore its menu bar and Dock.
  • Click Stop to end the current session without quitting.
  • Press Command-Q, click Quit, or close the control window to terminate the app cleanly.

7. Troubleshooting

The source keeps searching

  • Start the receiver before the source.
  • Confirm both Macs are running version 0.5.0.
  • Allow Local Network access and incoming firewall connections.
  • Confirm Thunderbolt Bridge is active on both Macs.
  • Use the receiver’s manual 169.254.x.x address.

The connection works, but there is no video

  • Enable Screen Recording permission on the source M1 Mac.
  • Quit and reopen the source app after changing that permission.
  • Clear the virtual-display checkbox and try mirror mode. This separates a virtual-display problem from a capture or network problem.

The image does not fill the screen

The receiver reports its current logical and Retina backing resolutions. Check its display scaling in System Settings → Displays, stop both roles, and reconnect after changing the scaling.

The old app will not quit

Open Terminal on that Mac and run:

killall IMacAsMonitor

Version 0.5.0 supports Command-Q and normal window-close termination.
